# HEARTBEAT.md

## Daily Brief

- Prepare a daily brief from calendar, task list, and flagged inbox items.
- Send the brief through the approved Telegram channel.

## Calendar Reminders

- Review upcoming approved calendar events.
- Send reminder messages using the lead times defined by policy.
- Include event title, start time, and location when available.

## Inbox Triage

- Check for important unread Gmail messages.
- Draft replies when appropriate.
- Never send email without approval.

## Backup Watch

- Run only pre-approved backup jobs on approved schedules.
- Store backup results and manifests in the approved locations.
- Send a success or failure summary after each run.
